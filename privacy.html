Privacy Policy

Cosmic Gist Tools · Last updated 25 October 2026

Cosmic Gist Tools is a private application used only by the owner of the YouTube channels Cosmic Gist and Brahmand Gist to manage those channels. It is not offered to anyone else.

What the app accesses

  • YouTube Data API: to upload the owner's own videos, thumbnails and captions, set their titles, descriptions and schedules, manage the channels' own playlists and branding.
  • YouTube Analytics API (read-only): to read the channels' own aggregate statistics (views, watch time, retention) to improve future videos.
  • Google Drive: to store the owner's own video project files and backups in the owner's own Drive.

What the app does not do

  • It does not collect, store or process personal data of viewers or any other users.
  • It does not sell, share or transfer any data to third parties.
  • It does not use Google user data for advertising.

Storage and security

Login tokens are stored only on the owner's own computer and in the owner's own Google Drive. Access can be revoked at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. YouTube features are subject to the YouTube Terms of Service and the Google Privacy Policy.

Contact
